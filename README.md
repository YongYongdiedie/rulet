# 구슬 대작전 — 한 컴퓨터에서 함께 플레이

진행자 컴퓨터에서 참가자 이름을 등록하고, 그 화면에서 구슬을 선택해 스킬을 사용하는 게임입니다. QR 참여와 휴대폰 동기화는 사용하지 않습니다. Firebase 연결도 필요하지 않습니다.

## 사용 방법

1. 참가자 이름을 한 줄에 한 명씩 입력하고 **참가자 등록 / 수정**을 누릅니다. 최대 30명이며 이름은 18자 이내입니다.
2. 등록 순서대로 1번부터 구슬이 배정됩니다. 빈자리는 봇으로 채워져 항상 구슬 30개가 출발합니다. 봇도 당첨될 수 있습니다.
3. **구슬 낙하 시작**을 누릅니다. 카운트다운 후 경기가 시작됩니다.
4. 참가자 목록의 이름 또는 **화면 추적 / 스킬 대상** 선택 상자로 참가자를 선택합니다. 화면이 그 구슬을 따라갑니다.
5. 선택한 참가자가 진행자 컴퓨터에서 **충격파 사용** 버튼을 누릅니다. 각 참가자는 경기 중 한 번만 쓸 수 있습니다. 다른 참가자로 바꿨다 돌아와도 사용 기록은 유지됩니다.
6. 충격파는 자신의 구슬도 포함해 반경 155px의 모든 구슬을 무작위로 밀어냅니다. 도착한 구슬과 봇은 스킬을 쓸 수 없습니다.
7. 모든 구슬이 도착하면 **가장 마지막에 도착한 구슬**이 당첨됩니다.
8. **새로운 경기 준비**를 누르면 이름과 구슬 배정은 유지되고 모든 참가자의 스킬이 다시 1회로 초기화됩니다.

**6명으로 체험하기**를 누르면 예시 참가자로 즉시 체험할 수 있습니다. 경기 중 이름/배정은 변경할 수 없으며 따라가는 참가자는 언제든 바꿀 수 있습니다. 선택한 구슬이 도착하면 화면은 아직 내려오는 구슬 중 가장 뒤처진 구슬을 따라갑니다.

## 코스

4,600px 높이의 S자 통로이며, 작은 핀 104개와 회전 장애물 4개가 있습니다. 최대 낙하 속도 341px/s, 중력 253을 사용합니다. 곡선 벽이 실제 충돌에 반영됩니다. 전체 구슬 위치는 오른쪽 미니맵에 표시합니다.

## 파일과 배포

index.html, style.css, app.js, README.md를 GitHub 저장소에 올리면 됩니다. 별도 설치나 빌드가 필요 없습니다. index.html을 브라우저로 열어 로컬에서도 플레이할 수 있습니다. 예전 config.js와 database.rules.json은 이 버전에서 사용하지 않습니다.

경기 중 탭을 계속 열어 두고 화면이 켜진 상태를 유지하세요. 백그라운드 탭이나 절전 상태에서는 브라우저가 게임을 멈출 수 있습니다. 새로고침하면 참가자 이름과 현재 경기는 초기화됩니다.

## 검사

참가자 등록/구슬 배정, 30명 제한, 참가자별 독립적인 스킬 1회, 선택 변경 후 재사용 차단, 경기 중 명단 수정 차단, 봇 스킬 차단, 마지막 도착 당첨, 재경기 이름 유지 및 스킬 복구를 검사했습니다. 자체 물리 구현을 사용하는 시제품입니다.
